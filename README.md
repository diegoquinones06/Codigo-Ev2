Aplicación web desarrollada con HTML, CSS y JavaScript que simula una casa inteligente mediante un ecosistema IoT. El sistema permite administrar dispositivos a través de un dashboard interactivo implementando las operaciones CRUD (Crear, Leer, Actualizar y Eliminar).

Cada dispositivo contiene información como nombre, tipo, ubicación, temperatura, nivel de batería y estado. Además, el sistema incorpora un buscador en tiempo real, alertas visuales para condiciones anormales y almacenamiento local mediante LocalStorage para conservar los datos.

### Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript
* LocalStorage

### Funcionalidades principales

* Agregar dispositivos.
* Visualizar dispositivos registrados.
* Editar información de los dispositivos.
* Eliminar dispositivos.
* Buscar dispositivos por nombre.
* Generar alertas por temperatura elevada, batería baja o dispositivos inactivos.

  En caso de querer aplicar el codigo, descargar el archivo "codigofinal.html" y ejecutelo como corresponda
